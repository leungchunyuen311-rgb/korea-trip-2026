【部署與使用方式】
1. GitHub Pages 免費託管（推薦）：
   - 將壓縮包解壓後的所有檔案（index.html, sw.js, manifest.json）上傳至 GitHub 倉庫的 main 分支。
   - 在 Settings -> Pages 中選擇 Deploy from branch (main / root)，即可獲得專屬 HTTPS 網址。
2. 加入手機主畫面（PWA Standalone App）：
   - iOS Safari：開啟網址 -> 點擊底部分享按鈕 -> 選擇「加入主畫面 (Add to Home Screen)」。
   - Android Chrome：開啟網址 -> 點擊右上角三點 -> 選擇「安裝應用程式」或「加到主螢幕」。
   - 安裝後全屏沉浸運作，支援離線緩存訪問！

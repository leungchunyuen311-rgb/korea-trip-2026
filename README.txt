【部署與使用方式】
1. GitHub Pages 免費託管（推薦）：
   - 將壓縮包解壓後的所有檔案（index.html, sw.js, manifest.json）上傳覆蓋至 GitHub 倉庫的 main 分支。
   - 在 Settings -> Pages 中確認 Deploy from branch (main / root)。
2. 手機端刷新（PWA Standalone App）：
   - Service Worker 快取已升級至 v28，手機重新打開網址或下拉刷新即會自動載入最新版！
   - 在 Safari 或 Chrome 選擇「加入主畫面 (Add to Home Screen)」，即可享受媲美原生 App 的全螢幕體驗。

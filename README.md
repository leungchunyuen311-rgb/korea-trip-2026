# korea-trip-2026

Lai's Family Seoul & Jeju Trip 2026 handbook.

Live: https://leungchunyuen311-rgb.github.io/korea-trip-2026/

## Enable the 2026 upgrade
`upgrade.css` and `upgrade.js` are already in this repo.

In `index.html`:
1. Inside `<head>`, add:
   `<link rel="stylesheet" href="upgrade.css">`
2. Just before `</body>`, add:
   `<script src="upgrade.js"></script>`

Then the site gets:
- tighter Lai's title spacing
- cleaner mobile hero
- Hong Kong vs Korea clocks
- live HKD/KRW rate
- live Seoul / Jeju weather
- search (`/` key)
- Today jump
- emergency sheet
- per-day notes + share
